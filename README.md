## 🛠️ Key Topics Covered

- **Basic Operations:** `SELECT`, `WHERE`, `DISTINCT`, filtering conditions, and logical operators (`AND`, `OR`, `NOT`).
- **Joins:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`, and `CROSS JOIN`.
- **Aggregations & Grouping:** `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, and `HAVING`.
- **Conditional Logic:** `CASE WHEN ... THEN ... ELSE ... END`, `IF()`, `COALESCE()`.
- **Subqueries & CTEs:** Common Table Expressions (`WITH`), nested queries, scalar subqueries, and correlated subqueries.
- **Window Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`.
- **String & Date Manipulation:** Pattern matching (`LIKE`, Regex), formatting, date arithmetic, and extraction.

## 🚀 How Solutions Are Organized

1. **Self-Contained Files:** Each problem folder includes the query solution file (`.sql`) and problem context.
2. **Standard SQL Flavors:** Primarily written in standard SQL (MySQL / PostgreSQL compatible).
3. **Commit History:** Maintained iteratively with progress updates as new problem sets are tackled.
